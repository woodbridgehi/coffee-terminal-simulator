### 字体子集再生（包外 `../tools/`）
新增文案后如需重新子集化（否则子集外汉字会回退到系统宋体）：
```bash
# 1) 把新文案并入字符集（去重后写入 tools/charset.txt）
# 2) 重建字体与封面路径
bash tools/rebuild-fonts.sh <source-han-serif-1.001R 目录> <JetBrainsMono-Regular.ttf> beijing-city-collection
```
`tools/outline-covers.py` 对已是路径的封面重跑无副作用（幂等），可安全重复执行。

## 字体系统
- `--font-display`：**思源宋体 CN**（包内 WOFF2），衬线标题；全部标题走 `font-weight:600` → 精确命中 SemiBold 字面（旧版落在系统宋体 Bold 上是向上取整的结果）。
- `--font-mono`：**JetBrains Mono**（包内 WOFF2）＋ 中文回退到包内思源宋体，确保任何平台的中文标签都不依赖系统字体。
- `--font-body`：系统无衬线（Inter / PingFang SC / 微软雅黑），末尾挂包内思源宋体作为中文兜底，杜绝缺字方框。
