## 2. 人员如何让新菜单生效

1. 备份该设备实例配置。等设备空闲并完成取杯；重启核验、制作中等状态先按原流程处理，不能靠更新菜单清除任务。
2. 本机这次的十款配方已放在 `config/instances/coffee-bot-003/recipes/`，材料定义在同级 `materials.json`，历史配方在 `recipe-archive/`。运行中的应用需要重新加载；本地模式可用已有重新加载配置入口，联网模式可用下述同步按钮。
3. 打开终端调试控制台，在“制作配方”区点击“同步菜单到后台”。该按钮重新加载已保存的配置，再请求上报；编辑框中尚未保存的文字不参与同步。
4. 等待状态从“等待同步”变为“已同步”，检查时间。失败会显示原因并由原连接循环重试；本地模式不会显示虚假的服务器同步成功。重新加载失败会提示对应配置问题。
5. 在对应设备的扫码菜单确认十款饮品及可售状态。库存不足可能导致下架，不能仅以后台收到菜单判断可售。

保存配方后原有自动同步仍保留；按钮用于主动重新加载、重发。按钮排队成功不等于服务器已接收，只有服务器确认后才显示已同步。更新仅作用于当前设备，不会自动广播其他设备。

## 3. 同步接口与版本

复用终端认证的 `PUT /api/v1/devices/{deviceId}/capabilities`，保留原 `products` 等字段，新增 `recipes` 数组承载完整配方（版本、步骤、材料、时长、拉花配置等）。服务端现有 Snapshot 模型允许额外字段，并将完整 payload 保存到 `terminal_snapshot`，不需要新建数据库表。库存仍使用原 inventory 接口。

服务器需返回 `ok: true`，终端记录 `receivedAt` 和本地能力版本。网络错误或未确认会显示失败；菜单/库存发送保持原有重试流程。手机公开菜单继续从 products 投影，完整 recipes 不因新增字段直接暴露给顾客。当前服务端保存的是最新设备快照，并非一个已实现的云端配方编辑、审核或下发系统。

已有五款保留 recipeId，升级为 3.0.0；新增石景山五款从 1.0.0 开始。旧版本已归档。调试保存升级版本前也会归档旧文件；终端收到排队旧订单的明确 recipeVersion 时，读取经过校验的对应历史版本并校验定制摘要，避免新菜单发布后旧订单直接版本不匹配。未知版本仍拒绝，当前已禁用的饮品仍不可执行。迁移时必须携带 recipe-archive，不能只复制最新版配方。

## 4. 联合交付包格式

调试控制台“品牌轮播”区新增“导出轮播＋配方交付包”，输出到当前实例 `exports/`，界面显示完整路径。导出包含当前启用的轮播包及已保存配方；会先重新加载校验配置，制作中或核验中拒绝导出。

```text
operations-<时间>-<随机标识>.zip
├── operations.json           # schemaVersion: 1, kind: coffee.operations-export
├── showcase.zip              # 当前启用的完整展示包，含包内字体
├── materials.json            # 材料定义，不是实时库存
├── recipes/<recipeId>.json   # 当前配方
├── recipe-archive/<recipeId>/<version>.json
└── README.txt
```

`operations.json` 记录创建时间、能力版本、展示包 id/version/file 和配方 ID 列表。外层联合包是运营交付/备份格式，**不能直接上传到轮播内容包管理器，也没有新增一键导入联合包功能**。第三方展示设计继续遵守 [展示包接口规范](showcase-partner-interface-v1.md)，不允许 HTML 操作配方接口。

人工迁移步骤：解压到暂存目录 → 审核材料、配方、版本和设备能力 → 备份目标实例 → 空闲时用交付 recipes 替换目标配方目录（避免旧文件残留导致重复 ID），合并所需历史归档并核对材料定义 → 重新加载校验 → 将内层 showcase.zip 在内容管理器导入、预览并启用 → 点击同步菜单并等待服务器确认。不要替换 device.json、认证凭据或运行状态数据库。回滚应保留期间新产生订单所需的配方版本。

本次示例：[北京城市联合交付包](../examples/operations/beijing-city-2026-1.0.0.zip)，包括十款配方及北京城市＋原展厅轮播内容。包不包含设备凭据、订单、顾客信息和实时库存。未来的一键导入应另做暂存校验、差异预览、空闲时原子切换与回滚，再纳入调试入口。
