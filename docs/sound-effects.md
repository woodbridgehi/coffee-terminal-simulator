# 制作过程声音

> 文档核对：2026-09-17。文中的旧日期、测试计数和截图是对应批次记录，不代表本次重跑或线上部署；当前索引见 [docs/README.md](README.md)。

终端主页由 `web/terminal-sound.js` 将声音偏好设为开启、音量100%，启动时尝试启用；浏览器或嵌入引擎若限制自动播放，会在首次点击/按键后再次尝试。切到后台时静音并断开，回到前台按终端偏好重试，用户主动关闭后不会自动重新开启。顾客订单页和独立 `robot-scene.html` 默认静音，需点击声音按钮启用。三维视图有独立的启停入口；不要把顾客页和终端主页的默认策略混为一谈。音量可调，完成语音为可选项。

包含萃取、加水、奶/拉花、糖浆循环声，以及夹爪、放杯、加冰、封盖短音。音效为本地 Web Audio 合成的示意声，并非真实硬件录音。状态提示继续依据订单权威状态；音效不驱动制作、不生成取餐码。系统缺少语音能力时仍有完成提示音。

`robot/sound-track.mjs` 从机器人动作段提取语义标记，`robot/process-audio.mjs` 使用已确认进度驱动唯一音轨。开启声音时才加载工序音频模块；无需打开三维。打开三维后跟随视图时钟，避免两套音效叠加。暂停、故障、等待重试、断线、后台或关闭视图均停止声音；终端超过 4 秒、顾客页超过 12 秒未更新时也停止工序声。初次进入、历史快照、跳转和重连不补播动作短音，演示拖动不触发订单完成播报。

动作去重键为任务、执行次数及动作标记，当前会话缓存最多 256 个事件。云端迁移 23 新增 `production_job.execution_attempt`，终端已有的 attempt 随事件入库并传递至顾客页，旧设备缺省为 1。部署需执行常规数据库迁移并重启服务。

修改后在模拟器目录运行 `npm run sync:cloud-scene`，同时构建并同步三维、工序音频和共享声音资源至云端。回归使用 `npm test`；云端执行 `node --test tests/*.mjs`，数据库测试设置独立 `TEST_DATABASE_URL`。浏览器需另行检查用户点击启用、过程播放、暂停与关闭，不以源码检查代替实际音频验证。
