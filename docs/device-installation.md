# 设备原点与安装关系

## 本轮计划与交付

统一设备安装坐标 → 拆分精细模型 → 同步碰撞体/工作点 → 增加配置与原点显示 → 检查候选布局 → 验证完整制饮。固定安装与临时抓取分开，保留旧配置。第一版采用命名安装点和数值编辑，不含鼠标拖拽或任意表面点击吸附。

## 页面使用

运行 `npm run twin:serve`，打开 `http://127.0.0.1:9131/device-lab.html`。

1. 选择设备，进入「设备配置」，滚动到「安装与原点」。
2. 勾选原点显示：红 X、绿 Y、蓝 Z。下方显示原点的世界坐标；夹爪安装原点随法兰运动。
3. 选择父安装点，修改位置（mm）与旋转（°，XYZ 欧拉角）。位置沿父坐标轴定义；切换父对象时自动重算局部位姿，保持世界位置。
4. 点击「保存设备配置」。保存前会检查所有未结束命令、持物状态、安装关系、当前碰撞，以及改变的工位是否存在机械臂逆解。失败保留旧配置与场景。
5. 用「定位设备」「碰撞几何」检查，再运行单步动作或一键制饮验证完整路径。逆解存在不等于路径一定无碰撞。
6. 「恢复此设备默认安装」只修改表单，保存后才应用。到「库存 / 会话」导出配置，可在下一次启动或导入时复用。

修改在服务进程中立即生效，并通知其他打开的联调页面更新布局；页面刷新不会复位。进程重启需使用导出的配置：

```sh
npm run twin:serve -- --config /绝对路径/device-lab-config.json
```

## 原点与父对象

| 对象 | 默认原点/父对象 | 可选父对象 |
|---|---|---|
| 普通设备 | 工位 X/Y 对应的台面安装参考点；父为 table:top | world、table:top、其他普通设备原点 |
| 机械臂 | 底座原点；父为 table:top | world、table:top、普通设备原点 |
| 夹爪 | 所属机械臂末端法兰；局部偏移为零 | 仅绑定机械臂的 left:flange 或 right:flange |

设备原点是安装参考，不保证恰好位于厂家模型的底面中心。模型、碰撞代理和接杯工作点各自保留相对原点的偏移。出料口通过设备几何及工作点随动。工作台表面坐标从工作台碰撞代理的上表面推导；表面相对原点的 X/Y 偏置也会显示在表单。

父设备移动/旋转时，所有子设备按父子变换一起更新。机器人底座变化时，底座及本机 ready 工作点更新；公共交接/取杯点仍属于工作台。台面与 world 本轮作为固定参考，不提供整台工作台移动控件。普通设备不能安装到运动中的机械臂末端，末端安装当前专用于夹爪，避免将固定工艺设备误用成动态设备。

夹爪安装偏移参与工具 TCP 计算，不只是视觉偏移。抓取成功时保存杯相对 TCP 的变换；释放清除临时附着并保留世界位姿。已有物品在移动前正好位于设备工作点（2 mm 内），会作为工位上的静置物品一起移动；其他自由物品保持世界位置，持物期间拒绝修改安装。

## 配置与接口

配置中的 `devices.<id>.mounting` 可省略，省略时推导旧布局。现有设备配置接口 `PUT /api/devices/{id}/config` 和配置导入/导出继续有效。需要当前 sessionId，并提交完整设备属性。

```json
{
  "parent": "table:top",
  "position": [0.70, 0.73, 0],
  "rotationDeg": [0, 0, 0]
}
```

上述是 mounting 字段示意，不是完整接口请求。JSON 内位置单位为 **米**，界面显示 **毫米**；角度均为度，旋转顺序 XYZ。世界坐标保持右手 Z 向上。位置每轴范围 ±20 m、角度 ±360°；不提供缩放。

`GET /api/state` 的 world.installation 包含有效 mounts、默认值 defaults、静态节点世界位姿 nodes、动态法兰节点及 nominalTools。动态法兰/工具节点需结合当前关节状态计算，CPU 模块 `installationPose(world,state,id)` 提供该计算。installationRevision 用于通知浏览器重新读取布局，不改变 sessionId。

## 验证与边界

- 旧配置的工位和障碍物保持精确不变。
- 单元测试覆盖父子平移/旋转、改父对象保位姿、循环/缺失父对象、非法值、碰撞、不可达、忙状态、持物限制、导入失败回滚、工具跟随与释放不跳变。
- 浏览器验证奶泡机横移 20 mm、模型完整保留、工位/奶杯同步、世界父对象切换、刷新保持、移动后 32 步制饮、恢复默认及窄屏布局。
- 保存时仅检查当前关节姿态的碰撞，并检查变更工位的逆解。安装改变后的整段运动仍由原规划器在执行时检查；尚无自动重规划全部配方的布局优化器。
- 原规划器偏好杯身直立和朝前设备口。大角度倾斜或大幅改布局可能使原配方无解，不能用保存成功证明整杯可执行。
- 碰撞仍使用原保守代理；本轮没有厂家 CAD、实际安装孔、夹爪运动几何或实机标定。静态布局检查拒绝新增/加深的穿插，保留旧模型已有接触。
- 尚不支持任意表面拾取、鼠标拖拽、任意新工具/物品动态挂载，以及安装点 CAD 自动识别。

机器人底座或工具位姿变化时，会重新检查全部工位的逆解；ready 点要求所属机器人可达。单台设备移动只检查受影响工位。
