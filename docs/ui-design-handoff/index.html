03 / 推荐交给设计软件的材料

  1. 上传本文件夹，包括 README.md、UI-SPEC.md、两个 HTML 与 assets。
  2. 要求先说明信息架构与状态语义问题，再给桌面和窄屏方案。
  3. 要求区分现有功能与新增提案；保留配置快照、命令去重、手动时钟和异常恢复语义。
  4. 交付组件状态、表单校验、空态/错误态、响应式与实现标注，而不仅是一张首页。

本包只重现联调台与实验室。原终端、三维展示及云端点单的范围和关系见 README。

相对路径组织，可复制整个文件夹给其他工具。若工具不读取 JavaScript，请同时提供 assets 中的桌面截图。
