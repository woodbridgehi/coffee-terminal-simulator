Geometry DNA

设计基因：五组可复用的几何母题

整套符号系统由五个基本形构成——圆角矩形、正圆弧、短横光标、S 曲线与 45° 网格点。任何新装饰图形都必须能用这五组母题拼出。

母题与规则

  1. 圆角矩形——杯身与容器的基础形，rx = 笔画宽的 1.75 倍；25×35 @64
  2. 正圆弧——杯柄、C 环、信号弧，全部来自同一圆心体系；R7 @64
  3. 短横光标——系统的签名元素：液面即终端光标 _，在 wordmark、terminal、ready 中复用
  4. S 曲线——咖啡豆裂线、蒸汽、注液流，共用同一曲率；c±7.5,8
  5. 45° 网格点——节点圆点与校准刻度，永远落在 8 的倍数上

笔画阶梯：4 @64 → 2 @24 → 1 @16，端点与转角一律圆头；黄铜在每个图形中最多出现一次，只落在光标、节点或对勾上。

Concept Exploration

六个概念：从杯沿到轨迹

先发散后收敛。六个方向共享同一色板与笔画语言，仅在几何母题的组合方式上彼此拉开差异。

杯沿光标Rim Cursor

杯身内唯一的横线既是液面，也是终端光标——杯子永远在等待下一条指令。第一眼是杯，第二眼是终端。

Final Candidates

Top 3 深化设计

杯沿光标Rim Cursor · Primary

核心想法
杯内唯一横线 = 液面 = 终端光标，杯体即待命状态的输入框。
几何构成
圆角矩形杯身 + 正圆弧柄 + 黄铜短横，共 3 个核心几何。
隐藏语义
光标与柄顶锚点同高（y=27），暗示「液面被系统精确标定」。
优势 / 风险
3 笔成立、16px 清晰、可眨眼化为加载态；风险是横线易被读成单纯水位，需靠系统复用强化光标语义。

豆径轨迹Bean Trajectory · Support

核心想法
豆子的裂线继续向上延伸，离开豆体后成为机械轨迹，终结于黄铜节点。
几何构成
椭圆豆体 + S 裂线 + 延伸弧 + 节点圆点，共 4 个核心几何。
隐藏语义
咖啡豆是被机器阅读的输入，节点是机械臂的末端执行器。
优势 / 风险
咖啡属性最强的候选、天然适合加载旋转；风险是小尺寸下延伸弧退化为普通豆子（可接受的优雅降级）。

注路轨迹Pour Path · Motif

核心想法
机械臂的运动轨迹与注咖啡的路径是同一条 90° 圆角折线。
几何构成
起点节点 + 两段正交圆角线 + 黄铜液滴，共 3 个核心几何。
隐藏语义
横线是传送带/路径，拐角半径与杯身 rx 一致——全系统共用同一圆角。
优势 / 风险
可无缝平铺为 Motion Path 图案、适合分节与流程；风险是咖啡属性靠液滴单点支撑，不单独作主 Logo。

Motion

品牌动效：只有三种，全部克制

符号系统的动效只有眨眼、呼吸与旋转三种母题，时长与缓动对齐全局规范；prefers-reduced-motion 下全部静止且不丢失状态。

动效用法规格
光标眨眼 blink加载中的主符号、字标光标steps(1) · 1.3s 循环
呼吸 breath在线点、LIVE 徽标、m-live 圆点opacity 1→.45 · 2.8s ease-in-out
旋转 spin进度弧、豆径轨迹加载1.6s linear · 仅 dasharray 弧段
悬停 / 按压品牌入口按钮（⌘ 控制台）100–160ms · cubic-bezier(.22,1,.36,1)
Reduced Motion全部动效animation:none，状态用静态高亮保留
眨眼加载黄铜光标以终端节奏闪烁，杯体保持不动
呼吸在线黄铜点呼吸，与顾客屏在线指示同源
进度弧单段圆弧旋转，永不做无限假进度
