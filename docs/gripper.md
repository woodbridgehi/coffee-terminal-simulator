# 独立末端夹爪（120 mm 仿真扩展）

设备联调服务新增 `left-gripper`、`right-gripper`，分别安装在左右机械臂。控制与查询仍使用现有 HTTP/SSE 接口；原离线仿真实验、TCP、配方和机械臂路径保持原样；设备联调的抓取/释放新增夹爪动作联动。旧配置未包含夹爪时仍可运行。

## 规格来源与边界

用户提供：开口 85 mm、单程全开合 2 s、自重约 0.7 kg、最大负载 2 kg；6 芯航插 RS485，支持串口协议、Modbus RTU、I/O。默认速度按 85 / 2 = 42.5 mm/s 推导，为**两指间距**变化速度，每根手指位移为间距变化的一半。未知加减速曲线，本版本为匀速，20 ms 固定步长，部分行程按距离/速度计算。启动延迟另计。

三维外观依据照片与尺寸图近似建模：银色壳体、黑色驱动座、双指、齿状接触面、侧面凹槽与状态灯；参考 110 mm 壳宽、60 mm 深度、81 mm 手指、85.6 mm 壳体与安装段。没有厂家 CAD，不视为制造级尺寸模型。模型安装沿用原工具旋转和 TCP，仅替换末端装饰，不修改机器人标定。

**默认仿真开口扩展为 120 mm，以适配直径 100 mm 的杯模型；原实物额定开口仍是 85 mm。** 扩展不代表真实硬件能力，外壳和滑轨也作示意加宽。默认速度保持 42.5 mm/s，120 mm 全行程按 20 ms 步长约为 2.84 s，而不是 2 s。

机械臂 `grasp` 会校验工具在线、故障、开口及负载：必要时先张开，再闭合到杯身直径，完成后才逻辑附着；`release` 先张开至上限，再释放。开合耗时使用各工具自己的速度配置，并计入命令耗时。工具停止或故障会中断关联抓取、保留中间开口，未完成抓取不会提前附着。独立开合命令本身不附着物体；持物时仍需通过机械臂释放。

未模拟夹持力、摩擦、防滑、接触检测或新手指几何碰撞。原碰撞代理保持不变。工具质量与额定负载是能力及状态校验信息，不参与惯性/力矩动力学。RS485、Modbus RTU、I/O 只是能力描述；未编写真实串口、寄存器或 I/O 电气驱动。

## 页面使用

启动 `npm run twin:serve`，打开 `http://127.0.0.1:9131/device-lab.html`：

1. 选择「左末端夹爪」或「右末端夹爪」，点「定位设备」看近景。
2. 「发命令」中选「指定开口」，填目标开口 40 mm、速度 20 mm/s，发送。时钟为手动时点击推进，实时模式自动执行。
3. 查看「实际开口」「目标开口」「开合中」「到达目标」及命令记录。停止后保留开口，未到目标不会误报到达。
4. 改做新动作时生成新命令 ID；同 ID 重发返回原结果。切换动作会自动生成新 ID。
5. 「设备配置」可修改初始开口、张开/闭合默认速度、开口上限和负载上限。初始开口仅重置会话后生效；设备复位只清故障，不移动手指。

## 配置

配置源：`config/twin/device-lab-v1.json` 中两台夹爪的 `gripper`：

| 字段 | 默认值 | 含义 |
|---|---|---|
| robot | left / right | 安装机械臂；运行时不可改 |
| maxOpeningMm | 120 | 最大两指间距，可降低但不能超过 120 |
| initialOpeningMm | 120 | 新会话初始开口 |
| openingSpeedMmS | 42.5 | 默认张开速度 |
| closingSpeedMmS | 42.5 | 默认闭合速度 |
| massKg | 0.7 | 名义自重，固定规格 |
| maxPayloadKg | 2 | 额定负载上限，可降低 |

仿真速度范围设为 0.1–42.5 mm/s；这是本版本的保守配置边界，厂商的实际速度调节范围尚未提供。公共 timing 中的 ackDelayMs、startDelaySeconds、sensorDelaySeconds、resetSeconds 继续有效；开合耗时由距离/速度决定，不使用通用 durationSeconds。

修改配置必须没有未结束命令，新上限不得低于当前实际开口。完整校验失败时保留原配置。两台工具可并行，同一机械臂与其工具的未结束命令互斥，避免独立开合和原抓取竞争。该规则仅作用于绑定机械臂/工具。

## 命令与状态

`POST /api/commands` 示例：

```json
{
  "sessionId": "从 GET /api/state 获取",
  "commandId": "left-jaw-position-001",
  "deviceId": "left-gripper",
  "action": "setOpening",
  "parameters": {"openingMm": 40, "speedMmS": 20},
  "startWithinSeconds": 30
}
```

- `open`：移动至配置最大开口；可选 speedMmS。
- `close`：移动至 0 mm；可选 speedMmS。
- `setOpening`：必填 openingMm，可选 speedMmS；省略速度按移动方向使用默认值。
- `stop`：停止本工具命令或关联的机械臂抓取/释放，保留当前开口。
- `reset`：清除故障/传感器强制值，保留当前开口，不意外张开。

`GET /api/devices/left-gripper` 返回能力、配置、state、sensors；state 含 openingMm、targetOpeningMm、speedMmS、mode。传感器按配置延迟发布，包括实际/目标开口、moving、atTarget、机械臂逻辑持物、持物宽度与重量、尺寸及负载兼容性。`robotHoldingObject` 来源于原逻辑附着，不是力传感器接触检测。

`GET /api/commands/{commandId}` 查询生命周期和结果；完成结果包含夹爪状态。沿用重复 ID 去重、取消、启动期限、离线、故障、丢通知恢复以及会话 ID 规则。停止/取消/故障保留中间开口，断连不会让已接收的运动自动停止。

## 验证

测试保留 85 mm/2 s 全行程，并增加 120 mm 抓取 100 mm 杯子、先闭合后附着、先张开后释放、闭爪后重新抓取和工具故障中断抓取；同时覆盖、部分行程速度、去重、取消/停止/故障保持、复位、配置原子性、两臂工具独立、机械臂/工具互斥、持物限制、断连与反馈恢复、几何双指对称开合。原完整制饮 HTTP 集成测试继续运行；浏览器额外验证开/闭近景、目标与速度输入、配置保存及窄屏布局。
